# Verb Conjugation Reference — the forms that decide the exam

Fast lookup for the irregulars and endings most likely to appear. If you can produce
every form on this page cold, the conjugation half of the exam is handled.

## Regular endings (baseline)

| Tense | -ar (hablar) | -er (comer) | -ir (vivir) |
|---|---|---|---|
| Present | -o -as -a -amos -áis -an | -o -es -e -emos -éis -en | -o -es -e -imos -ís -en |
| Preterite | -é -aste -ó -amos -asteis -aron | -í -iste -ió -imos -isteis -ieron | (same as -er) |
| Imperfect | -aba -abas -aba -ábamos -abais -aban | -ía -ías -ía -íamos -íais -ían | (same as -er) |
| Future | infinitive + -é -ás -á -emos -éis -án | (same) | (same) |
| Conditional | infinitive + -ía -ías -ía -íamos -íais -ían | (same) | (same) |
| Pres. subj. | -e -es -e -emos -éis -en | -a -as -a -amos -áis -an | (same as -er) |
| Imperf. subj. | 3pl preterite stem + -ra -ras -ra -´ramos -rais -ran | (same) | (same) |

**Imperfect — only 3 irregular verbs total:** *ser* (era, eras, era, éramos, erais,
eran), *ir* (iba, ibas, iba, íbamos, ibais, iban), *ver* (veía, veías…).

## Preterite irregulars (u/i/j-stem group — no accents on yo/él)

| Verb | Stem | yo / él,ella |
|---|---|---|
| estar | estuv- | estuve / estuvo |
| tener | tuv- | tuve / tuvo |
| poder | pud- | pude / pudo |
| poner | pus- | puse / puso |
| saber | sup- | supe / supo |
| hacer | hic- (hizo) | hice / hizo |
| querer | quis- | quise / quiso |
| venir | vin- | vine / vino |
| decir | dij- | dije / dijo (ellos **dijeron**) |
| traer | traj- | traje / trajo (ellos **trajeron**) |
| conducir | conduj- | conduje / condujo (…**condujeron**) |

**Fully irregular preterite:** *ser/ir* → fui, fuiste, fue, fuimos, fuisteis, fueron
(identical for both — context decides). *dar* → di, diste, dio, dimos, disteis, dieron.
*ver* → vi, viste, vio, vimos, visteis, vieron.

**Spelling-change preterite (yo only):** *-car* → **-qué** (buscar → busqué), *-gar* →
**-gué** (llegar → llegué), *-zar* → **-cé** (empezar → empecé).

**3rd-person stem/spelling changes (-ir verbs and i→y):** *pedir* → pidió/pidieron,
*dormir* → durmió/durmieron, *servir* → sirvió, *preferir* → prefirió; *leer* →
leyó/leyeron, *oír* → oyó/oyeron, *construir* → construyó.

## Present-tense irregulars (high frequency)

- **yo-irregular:** hacer→hago, poner→pongo, salir→salgo, tener→tengo, venir→vengo,
  decir→digo, traer→traigo, conocer→conozco, ver→veo, dar→doy, saber→sé, caer→caigo.
- **stem-changing:** e→ie (querer/pensar/empezar/preferir), o→ue (poder/dormir/volver/
  contar), e→i (pedir/servir/repetir), u→ue (jugar). Note the "boot": no change in
  nosotros/vosotros.
- **fully irregular:** ser (soy, eres, es, somos, sois, son), ir (voy, vas, va, vamos,
  vais, van), haber (he, has, ha, hemos, han), estar (estoy, estás, está, estamos, están).

## Present subjunctive — irregular stems (from yo-form) 

pongo→**ponga**, tengo→**tenga**, salgo→**salga**, digo→**diga**, hago→**haga**,
oigo→**oiga**, vengo→**venga**, conozco→**conozca**, traigo→**traiga**.
**Six memorize-outright (DISHES):** dar→**dé**, ir→**vaya**, ser→**sea**, estar→**esté**,
haber→**haya**, saber→**sepa**. Stem-changers keep the change; -ir stem-changers also
change in nosotros (dormir→durmamos, pedir→pidamos).

## Future / Conditional — 12 irregular stems (shared)

decir→**dir-**, hacer→**har-**, poner→**pondr-**, tener→**tendr-**, salir→**saldr-**,
venir→**vendr-**, poder→**podr-**, saber→**sabr-**, querer→**querr-**, haber→**habr-**,
valer→**valdr-**, caber→**cabr-**. (Future adds -é/-ás/-á/-emos/-án; conditional adds
-ía/-ías/-ía/-íamos/-ían.)

## Past participles (for perfect tenses) — irregulars

abrir→**abierto**, decir→**dicho**, escribir→**escrito**, hacer→**hecho**,
morir→**muerto**, poner→**puesto**, romper→**roto**, ver→**visto**, volver→**vuelto**,
cubrir→**cubierto**, resolver→**resuelto**, descubrir→**descubierto**,
devolver→**devuelto**. (Regular: -ar→-ado, -er/-ir→-ido; note accents: leído, traído, oído.)
