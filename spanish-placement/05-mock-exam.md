# Mock Exam — 90-minute simulation

Test-day rehearsal. **Rules:** one sitting, 90 minutes, no notes, no dictionary. Do the
grammar (45 items, ~45 min), reading (10 items, ~20 min), then the essay (~25 min).
Answer key at the bottom. Target for top placement: **≥ 90% on grammar**, all reading,
and an essay hitting every requirement in `04-reading-and-writing.md`.

_Note on 40: **c) cuyo** — "whose" agrees with the owned noun *padre* (masculine), so
*cuyo*. Contrast the practice-bank item where the owned noun was *madre* (feminine) →
*cuya*. Same rule, opposite gender: a deliberate trap._

### One-line rationales for the tricky ones
- **8/20/25** pronouns: le→**se** before lo; DO "lo" for masc. person; affirmative
  command attaches + accent (*Dámelo*).
- **10/26/45** *si*-clauses: imperfect subj. in the *si* half, **conditional** in the
  result (*tuviera → compraría*); past counterfactual → *hubiera + habría*.
- **11/32/37** time clauses: future/unrealized → subjunctive (*llegues, salga, salgas*).
- **30** *como si* → **always** imperfect subjunctive (*supiera*).
- **36** "who did it" one-time bounded event → **preterite** *fue*.
- **40** *cuyo/cuya* agrees with the **owned** noun: *cuyo padre* (masc.) → **cuyo**.
